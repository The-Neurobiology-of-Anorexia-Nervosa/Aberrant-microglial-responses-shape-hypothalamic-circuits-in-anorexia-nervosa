# RNA-seq analysis

This module contains code for RNA-seq quality control, normalization,
differential-expression analysis, GSEA/FGSEA and figure generation.

## Directory contents

- `scripts/`: R scripts in their intended execution order
- `data/metadata/`: non-identifying sample and experimental metadata
- `data/external/`: documentation for externally deposited data
- `data/processed/`: documentation for processed input matrices
- `data/reference/`: gene annotations and permitted reference files
- `results/`: complete statistical results and figure source data
- `figures/`: figures generated by the analysis

## Required inputs

Required input files and repository accession numbers will be listed here.

## Analysis order

1. Data preparation
2. Quality control and normalization
3. Differential-expression analysis
4. Preparation of ranked gene lists
5. GSEA/FGSEA
6. Figure generation

## Data availability

Raw and large processed files are not stored in GitHub. See the main
repository README and `config/config_template.yml`.
