# Microglial-state enrichment analyses

This module contains Fisher's exact tests and FGSEA analyses comparing
study-derived results with published human and mouse microglial-state
markers.

## Directory contents

- `scripts/`: data preparation, Fisher-test, FGSEA and plotting scripts
- `data/metadata/`: descriptions of microglial states and marker sets
- `data/external/`: public marker tables or instructions for obtaining them
- `data/processed/`: study-derived DEG tables used as inputs
- `data/reference/`: permitted reference gene sets
- `results/`: complete Fisher-test and FGSEA results
- `figures/`: figures generated by the analysis

## Required inputs

Each input must be documented with:

- Dataset or paper citation
- DOI and repository accession
- Exact original filename or supplementary table
- Local expected filename
- Required columns
- Preprocessing and gene-identifier conversion
- Script that generated study-derived inputs

## Analysis order

1. Prepare human and mouse microglial marker sets
2. Perform Fisher's exact tests
3. Prepare ranked gene lists
4. Perform FGSEA
5. Generate figures
