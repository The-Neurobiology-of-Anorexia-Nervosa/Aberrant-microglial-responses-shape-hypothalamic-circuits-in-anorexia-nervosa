# Spatial transcriptomic analysis

This module contains code for spatial transcriptomic quality control,
normalization, differential-expression analysis, pathway analysis and
figure generation.

## Directory contents

- `scripts/`: R scripts in their intended execution order
- `data/metadata/`: sample, animal and ROI metadata
- `data/external/`: documentation for externally deposited data
- `data/processed/`: documentation for processed expression matrices
- `data/reference/`: platform and gene-annotation files
- `results/`: complete statistical results and figure source data
- `figures/`: figures generated by the analysis

## Required inputs

Required input files, platform information and repository accession numbers
will be listed here.

## Analysis order

1. Data preparation
2. Spatial quality control
3. Normalization
4. Differential-expression analysis
5. Preparation of ranked gene lists
6. GSEA/FGSEA
7. Figure generation
